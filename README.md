# Лабораторная работа №1 - Продвинутый NumPy

**Автор:** Парамонов Даниил Дмитриевич, группа 1521741, 3 курс

Пять задач по продвинутому NumPy:

1. **Числа с плавающей точкой** - точность `float32` / `float64`, машинное эпсилон, катастрофическая отмена.
2. **Индексация, срезы и broadcasting** - базовые срезы, fancy-индексация, логическая индексация, broadcasting.
3. **Memory-mapped файлы и оптимизация кэша** - `np.memmap`, сравнение обхода по строкам и по столбцам.
4. **Разреженные матрицы** - форматы CSR / COO / CSC, сравнение с плотными матрицами.
5. **Cython** - сумма квадратов на чистом Python и на Cython, замер ускорения.

## Структура

| Файл | Назначение |
|---|---|
| `lab_numpy.ipynb` | Решение всех пяти задач с результатами и выводами (Jupyter-ноутбук) |
| `sum_squares.pyx` | Cython-реализация суммы квадратов (задача 5) |
| `setup.py` | Сборка Cython-расширения |
| `requirements.txt` | Зависимости |

## Как запустить

```bash
pip install -r requirements.txt
jupyter notebook lab_numpy.ipynb
```

Cython-модуль компилируется прямо из ноутбука (ячейка в задаче 5). Для этого нужен компилятор C
(Linux: `gcc`; Windows: Microsoft C++ Build Tools; macOS: Xcode Command Line Tools).
Скомпилировать можно и вручную:

```bash
python setup.py build_ext --inplace
```
